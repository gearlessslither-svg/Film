# Idea Board / 创意分镜板

- Project / 项目: coin-slot
- Updated / 更新时间: 2026-06-18T23:16:03+08:00
- Story title / 片名: 投币口 / Coin Slot
- Logline / 一句话: 90年代北方小城里，三个放学后的孩子偷偷钻进居民楼角落的游戏机房，第一次跨进成人世界灰色而诱人的门缝。

## Idea / 创意
第二幕，三个小朋友进入游戏厅，两个小弟弟被这种光怪陆离的气氛震慑住了，哥哥则装着满脸成熟的样子，掏出一块钱和老板买了三个游戏币（钱和游戏币要给特写，要真实，突出年代感）驾轻就熟的来到一台真人快打前，开始打游戏，哥哥一直赢，两个弟弟非常开心，四周围绕的人也越来越多，突然一个黄毛走到同一台机器的副操作位，二话不说投币挑战哥哥，哥哥有些惊讶但依然应战，赢了，黄毛骂骂咧咧满脸不爽的再次投币，又输，（快速剪辑几个投币特写，表情狰狞，叫骂特写），终于，黄毛走了，走的时候恶狠狠的盯了哥哥一眼，什么都没说

## Story Outline / 剧本大纲
第一幕：三个孩子从学校离开，绕到破旧居民楼角落，进入隐藏游戏厅。

第二幕：三个孩子在游戏厅买币、玩真人快打，哥哥连胜引来同龄黄毛小痞子的挑战；黄毛连输后离开前留下威胁性的凝视。

## Style Notes / 风格备注
年代和地域：上世纪90年代中国北方小城，冷灰水泥、旧砖墙、锈蚀铁门、褪色校服、旧书包、CRT 街机光。镜头语言：外部用远景/中景保持写实观察，门口用猫眼、门缝、手和脸的近景制造进入禁区的仪式感，内部用儿童视角和宽镜头展示烟雾、拥挤和鱼龙混杂。角色连续性：三个孩子始终同一组设定，背书包，年龄相近但姿态性格略有差异；老板是熟悉他们的中年男性，只在开门环节短暂出现。负面约束：不要现代智能手机、现代商场、赛博朋克霓虹、夸张恐怖片氛围、卡通化表演、随机可读文字、水印、无关主角。

第二幕新增约束：所有混混/黄毛都应是初中生年纪、和哥哥差不多大，是小痞子而不是成年人；保持90年代中国北方小城真实游戏厅质感，烟雾、旧荧光灯、CRT街机屏幕、脏墙面、塑料凳和围观人群都要服务叙事，不要变成现代电竞厅。

## Acts / 幕结构

### 01. ACT01 第一幕：进入游戏厅 / Entering the arcade
- Status / 状态: draft
- Dramatic purpose / 戏剧功能: 建立年代、地点、三兄弟关系和禁忌空间的吸引力，让观众理解孩子们为什么紧张又兴奋。
- Key beats / 关键节拍: 放学偏离大路、靠近旧楼角落、猫眼确认、门缝打开、进入游戏厅、鱼龙混杂全貌

三个孩子放学后绕开大路，鬼鬼祟祟来到破旧居民楼角落的隐藏游戏机房。老板从猫眼确认熟人后开门，孩子们第一次进入乌烟瘴气、鱼龙混杂的空间。

### 02. ACT02 第二幕：真人快打挑战 / Mortal Kombat challenge
- Status / 状态: draft
- Dramatic purpose / 戏剧功能: 把游戏厅从“诱惑空间”推进成“压力空间”：哥哥的熟练和虚张声势带来短暂胜利，也引出同龄小痞子的敌意。
- Key beats / 关键节拍: 进入厅内被震慑、哥哥买币、钱与游戏币特写、来到真人快打、哥哥连胜、围观变多、黄毛插入挑战、黄毛连输失控、离开前凝视威胁

三个孩子进入游戏厅后，两个弟弟被烟雾、霓虹和成年人混杂的气氛震住，哥哥装成熟地买下三个游戏币，熟练走向真人快打机并连胜。围观人群变多，一个与哥哥年龄相仿的黄毛小痞子突然投币挑战，输后连续投币、叫骂，最终离开前恶狠狠盯着哥哥，为后续冲突埋下不安。
