# V2 人设与关键帧试片包

## 人设板

阿白双状态：左侧工厂状态，深蓝统一工装、额前黑毛露出；右侧演出状态，脱下工装、左肋唯一黑纹可见、持旧小提琴。附正面、侧面、背面和两种克制表情。9:16 纵向旧纸蛋彩板，无文字。

## 首批六张关键帧

1. 灰晨工厂：不同物种穿完全相同的深蓝工装，轴对称排队打卡；阿白在队伍中凭额前黑毛被找到。
2. 停机回望：动物队列下班，阿白在巨大停住的机器前独自回头。
3. 脱去制服：高俯视公共更衣室，整齐堆放的相同工装与显露的不同毛色形成对比；阿白左肋黑纹首次完整出现。
4. 取回自己：动物们打开旧箱，拿乐器、酒、华服；阿白抱起小提琴，大象尝试扣上过小礼服。
5. 广场狂欢：赭金灯光、旧红与深青华服；笨拙跳舞、跑调歌唱、饮酒；阿白在边缘拉琴后逐渐走入人群。
6. 工厂谢幕：人群与动物并排，远处烟囱安全拆除；随后互换小物、整理衣领、点头拥抱，阿白把琴盒交给幼猫。

## 统一画风指纹

严格继承导演参考的旧纸蛋彩、水粉哑光、深青蓝与赭金、纵向寓言构图、平面化空间、略失真人物比例与冷静荒诞；整体亮一档、温暖一档，禁止写实绘画、照片、3D、日漫、糖果色和恐怖黑暗童话。
