# ENV-02 广场／舞蹈大厅场景设定 V1

[NARRATIVE_TIME] 60–96 秒；演出开始前的空场设定，傍晚即将入夜。

[CHARACTER_STATE_LOCK] 无角色；只建立最后演出、舞蹈与远望烟囱所需的共享空间。

[STATE_TRANSITION_RULE] 本图禁止人物、动物和状态变化；只锁定场景美术与轴线。

[STYLE_FINGERPRINT] 严格继承导演 DFT 参考：旧纸哑光蛋彩／水粉，大块深青阴影、赭金灯光、褪砖红和暖灰；平面化透视、安静荒诞、克制童话感，细节集中在建筑轮廓与灯光路径。不是写实，不是3D，不是日漫。

[SUBJECT_AND_ACTION] 红砖宿舍与旧礼堂围成的小镇中央广场。礼堂一层的大门完全打开，能看见内部朴素舞蹈大厅和二层窄看台；大厅与室外广场在同一条视线上。广场中央是低矮木台，侧面一张长桌，空旷舞池延伸进大厅。稀疏串灯跨过广场。远景屋顶之间能看到一根完整、无烟的工厂烟囱，用于后续倒塌方向锁。

[CAMERA_AND_COMPOSITION] 21:9 超宽建立镜头，广场对角线上的略高机位，约28–32mm镜头感。前景为暗色拱门或砖墙边缘，中景完整广场、木台和舞池，后景礼堂开门、二层看台与更远的无烟烟囱。构图必须同时提供平视表演、看台俯拍、舞台反打和长焦望烟囱的可用轴线。

[LIGHTING] 蓝灰暮色覆盖天空与砖墙阴影，串灯和礼堂内部发出克制赭金暖光；不做节庆糖果色。光线从灰蓝缓慢转暖，但场景仍带离别前的苍凉。

[SPACE_AND_CONTINUITY] 低木台位于广场偏侧，不堵住舞池；礼堂开门与舞池相连；二层看台能俯看大厅并越过门看到广场；烟囱始终在礼堂外远景同一方向。通道可容纳大象和熊，舞池保留多物种松散活动空间。

[INTENTIONAL_REALITY_EXCEPTIONS] 仅允许DFT平面化透视；建筑、看台、门洞、舞台和串灯仍遵守正常支撑与尺度。

[NEGATIVE] 无角色、无动物、无乐队、无乐器墙、无文字、无招牌、无伪文字、无烟花、无魔法光、无游乐园、无婚礼场地、无豪华剧院、无现代舞台灯、无末日废墟、无火灾；烟囱绝对无烟。禁止照片写实、3D渲染、日漫、水彩晕染、厚重油画、暗黑恐怖。清晰大形体、受控细节、自然边缘、低噪点；无颗粒、随机斑点、泥状微纹理、过锐光晕、假像素细节和JPEG伪影。
