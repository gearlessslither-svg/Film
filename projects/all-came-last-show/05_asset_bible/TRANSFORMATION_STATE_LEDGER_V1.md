# 全体角色三状态与转换账本 V1

## 共通状态

### `FACTORY_BIPED_UNIFORM`

- 两足拟人工人；直立脊柱、两臂两爪／蹄、两腿两足、一尾。
- 完全相同版式的深蓝旧棉工装，按体型合理放码。
- 不携带私人乐器；动作重复、克制。

### `PERFORMANCE_BIPED_PRIVATE_DRESS`

- 保持同一个体身份与两足拟人结构。
- 穿私人华服，可持经批准的单一乐器或生活道具。
- 乐器空间规则：同一前景表演点只设一个主乐器；不同乐器分散在前中后景或不同镜头，禁止并排密集陈列。

### `WILD_RETURN_QUADRUPED`

- 完全四足、无衣物、无拟人肩线、无可抓握人形前爪、无直立站姿。
- 身体比例、脊柱、骨盆、四肢、足部和步态回到真实物种；仍以 DFT 旧纸蛋彩翻译，不转照片写实。
- 阿白必须精确回到三张照片共同定义的四足长毛白猫身份：灰绿色眼、粉鼻、头顶非对称灰黑斑、背部鞍状灰黑斑、深灰蓬松尾巴。
- 其他动物分别回到真实四足绵羊、大象、驴、狗、狐狸、兔和熊结构。
- 禁止残留衣袖、纽扣、工帽、鞋、乐器、酒杯与人形手。

## 唯一状态边界

- `[STATE_TRANSITION_RULE]` 只有在最后演出结束、华服被脱下且工装确认丢失后，才允许从 `PERFORMANCE_BIPED_PRIVATE_DRESS` 进入 `WILD_RETURN_QUADRUPED`。
- 变形开始前所有角色保持两足；变形结束后所有离城镜头保持四足。禁止提前四足、半人半兽残留或后续又直立。
- 转换镜头必须拆成至少三个连续锚点：两足脱下最后衣物 → 重心前移、前肢落地但身份稳定 → 完整四足野生状态。全过程无痛苦、无身体恐怖。

## 道具状态

- 工装：在转换边界前已经确认丢失，不得在结尾重新出现。
- 华服：脱下后保持普通衣物结构，不自动燃烧、溶解或化为动物皮毛。
- 乐器：完整收好或留在原地，禁止破裂、缺弦、埋入身体或随变形融合。
