# 核心场景候选设定 V1

## 西北小镇工厂外部

灰蓝晨雾中的真实人类尺度红砖厂区：高烟囱、旧打卡室、重复窗格、宽而空的水泥地、停住的传送设施。建筑高得略显压迫但功能可信，不是动物玩具城。主色灰蓝、煤灰、褪砖红，少量旧芥末灯光。

## 公共更衣室

真实工业更衣室：高窗、长木凳、成排深青铁柜、磨损水泥地、暖灰顶灯。空间可供大象与小型动物共同使用，柜门与通道尺度合理。相同工装整齐叠放形成重复秩序，不用脏乱杂物堆叙事。

## 中央广场

红砖宿舍与旧礼堂围成的小镇广场，中央有低矮木台、串灯、长桌和空旷舞池，远处能看见工厂烟囱。傍晚从灰蓝过渡到赭金、旧红与深青；欢乐来自人群动作和灯光，不用糖果色、烟花或魔法特效。

以上均为 lookdev 候选，导演通过后再拆成独立场景硬锁与空间连续性图。
