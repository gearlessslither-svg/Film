# 《所有人都来了》项目简报

- 形式：无对白现代彩色默片，目标时长 105 秒，硬上限 120 秒。
- 核心议题：不被市场需要的能力，仍然属于一个人；一座资源枯竭型小城用最后一场无用的演出为自己送别。
- 主角：年轻的拟人白猫工人，身体只有一道黑色条纹、额前一撮黑毛；它不是纯种猫，也不是可爱吉祥物。
- 世界：小镇居民全部是拟人动物，直立行走、穿工作服、使用人类工具；工厂、宿舍、浴室、广场、乐器和酒具全部保持真实的人类工业尺度与功能。
- 视觉：采用导演提供的童话参考系——纵向寓言构图、旧纸蛋彩质感、深青与赭金、平面化造型、安静荒诞；由阴郁黑暗调整为落寞但温暖的工业送别，不复制参考图中的具体角色或画面。
- 当前阶段：只做一张综合美术测试板，含主角人设与四个关键帧；未获导演批准前不扩批。
