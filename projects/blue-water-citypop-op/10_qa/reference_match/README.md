# Reference Match QA

This folder stores QA for video-reference remake work.

## When To Use

Use after Codex has generated remake outputs: keyframes, Blender playblast, AIGC video clips, or edited sequence.

## Checks

- Timing: durations and cut points match the reference plan.
- Unit count: one-take, montage, transition, title-safe hold, and character-intro units match accepted decisions.
- Composition: subject placement, negative space, horizon/sky ratio, and screen direction are close to reference.
- Motion: camera movement and object travel direction are faithful where intended.
- Transitions: light flares, match cuts, wipes, or hard cuts occur at accepted timecodes.
- Safety: no generated readable logo, subtitle, watermark, or copied title text in pure-generation outputs.
- Drift: characters, costumes, props, and spaces remain consistent with the live-action remake bible.
