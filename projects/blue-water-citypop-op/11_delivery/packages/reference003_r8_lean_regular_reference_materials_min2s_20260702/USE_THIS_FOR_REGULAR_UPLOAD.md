# Use This For Regular Upload

This package contains only source-independent reference clips whose original shot duration is at least 2 seconds.

Use per unit:

1. `01_reference_clip/*_upload_h264_aac.mp4`
2. `02_keyframes_for_upload/`, if present
3. `03_asset_locks_for_upload/`
4. `AIGC_PROMPT.md`

Do not pull short units from the old 36-unit package. Short units are separated here:

`../reference003_r8_lean_short_reference_materials_under2s_20260702/`

Shot content integrity has higher priority than the 2-second upload rule. Do not merge or splice neighboring shots.
