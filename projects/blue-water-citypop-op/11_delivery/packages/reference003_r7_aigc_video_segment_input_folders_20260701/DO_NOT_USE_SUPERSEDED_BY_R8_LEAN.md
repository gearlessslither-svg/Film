# Do Not Use This Package

This R7 folder package is superseded by:

`../reference003_r8_lean_aigc_video_segment_input_folders_20260701/`

Reasons:

- `01_reference_clip/` files are original `mp4v` / no-audio split clips and may be rejected by upload sites.
- `02_keyframes_for_upload/` mixes official/original frames, R5 target-style generated frames, and R7 generated candidates.
- The mixed upload set can push external AIGC video generation into the wrong timing, identity, and style.

Use the R8 lean package instead.
