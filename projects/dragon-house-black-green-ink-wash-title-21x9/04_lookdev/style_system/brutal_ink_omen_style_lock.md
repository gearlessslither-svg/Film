# Brutal Ink Omen Style Lock

Project: `dragon-house-black-green-ink-wash-title-21x9`
Track: `Brutal Ink Dragon Omen`
Aspect: 21:9 delivery, with a vertical poster-like power column allowed inside the wide frame
Status: sole active visual style

## Sole Approved Reference

Use only the director-approved screenshot archived at:

- `04_lookdev/style_references/brutal_ink_omen_v1/director_reference_only_style.png`

Do not learn from the earlier shadow-puppet / cut-paper / ornate-card experiments. They were separate rejected explorations for this branch. Do not blend them into this style.

The target feeling is brutal, clean, imperial, and lethal:

- one overwhelming black ink dragon stroke
- one cold isolated figure or power symbol
- old rice paper ground
- violent dry brush, ink splatter, flying-white gaps
- sparse mineral green stain
- sparse cinnabar seal-like blocks with no readable characters
- faint antique-gold crack lines only as restrained texture
- strong black border or burned-paper vignette

## Hard Exclusions

Avoid these unless explicitly requested for a different branch:

- all shadow-puppet theatre language
- cut-paper, leather-puppet, rods, hinge joints, bead mechanisms, pierced lace, ornate stage frames
- soft landscape-first composition
- palace/court/army scene as the main subject
- dense scenic detail spread across the whole frame
- pretty portrait, actor likeness, photoreal dragon flesh, anime, generic western fantasy concept art
- readable text, names, logos, official symbols, readable seals, map labels, watermarks

## Composition Rules

Each final keyframe should pass this test:

1. Can the frame be described as one lethal ink gesture plus one iconic subject?
2. Does the dragon or power mark dominate before the background does?
3. Is the paper negative space clean enough that the image feels severe rather than busy?
4. If a character is the subject, can we read the full figure silhouette and mask-like face?

If the answer is no, the frame is still too scenic or too decorative.
