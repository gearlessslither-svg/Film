## Style Rule

Use only the active `Brutal Ink Dragon Omen` style: splashed black ink, old rice paper, dry brush, flying-white gaps, sparse mineral green, sparse cinnabar, faint antique-gold cracks, severe negative space.

Do not use shadow-puppet, cut-paper, leather-puppet, ornate-card, black-gold card, soft scenic ink wash, old Blender proxy style, readable text, logos, actor likeness, exact official costume, or readable sigils.

## Audio Rule

Every AIGC video prompt in this package includes the hard rule:

Sound effects and ambience only; no music, no BGM, no soundtrack.
