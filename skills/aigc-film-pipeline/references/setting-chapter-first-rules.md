# AIGC 影视设定章节先行规则 v1

## Gate 0

完整流程永远从设定章节开始。无论项目由剧本、参考视频、图片、口头点子还是混合材料发起，第一件事都是生成并确认设定章节。设定章节确认前，禁止进入镜头排产、白模、关键帧生成、AIGC 视频包、粗剪或最终交付。

## 设定章节必须包含

- 人物：所有主要角色、次要角色、群像中可辨认角色、年龄/体态/脸型/发型/服装/饰品/习惯动作/禁区。
- 道具：核心道具、手持物、佩戴物、标志物、武器/工具、UI/屏幕元素、可重复出现的小物。
- 车辆/动物/机械/符号：飞行器、船、车、动物伙伴、徽记、宝石、能量体、标题安全替代图形等。
- 场景：所有主要地点、过渡地点、背景环境、空间结构、时代信息、光源、色彩、天气/水体/天空状态。
- 风格：画幅、摄影语言、材质、色彩、时代质感、禁用元素、文字/logo/水印策略。
- 阶段状态：角色服装变化、伤痕/泥灰/情绪、道具状态、场景破坏或时间变化。
- 锁图计划：哪些资产已有 `official_*_lock`，哪些还需要生成或挑选。

## 不同起点的处理

- 剧本起点：先从剧本抽取设定章节，再拆幕、视频单元、镜头和关键帧。
- 视频起点：先从参考视频抽取设定章节，再做镜头分析和 1:1 复刻规划。参考视频提供时序、机位、运动和剪辑功能；设定章节决定角色、道具、场景和风格一致性。
- 图片起点：先把已给图片归档为候选设定锁图，再确认哪些可成为官方锁图，哪些只是 mood/reference。
- 混合起点：先合并成一个设定章节，解决冲突后再排产。

## 确认门禁

- 设定章节必须由导演确认，或明确标记为 `provisional_setting_approved_for_test_only` 才能做小规模测试。
- 没有确认的资产标为 `needs_setting_lock`，不能在正式群像、关键剧情镜头或视频生成中可见。
- 一旦锁定，后续镜头只能改变机位、动作、表情、光照和阶段状态，不能换脸、换核心服装、换道具造型、换地点结构或换风格体系。

## 生产失败判定

- 漂亮但换脸：失败。
- 构图对但道具变形：失败。
- 运动对但场景结构换了：失败。
- 大合照人物不像锁图：失败。
- 视频模型把设定章节里的资产替换成新设计：失败，必须返修。
