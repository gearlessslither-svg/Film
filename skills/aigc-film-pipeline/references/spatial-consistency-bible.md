# 投币口 / 01_AIGC 空间一致性圣经 v1

## 当前问题

之前生成图像有跑偏风险：同一场景内入口方向、人物站位、镜头轴线、空间尺度和光源可能在不同图之间漂移。AIGC 如果只吃单条画面提示词，会倾向于重新发明空间。

解决方案不是把提示词写得更长，而是建立“场景锁定 -> 白模机位 -> panel 生成 -> contact sheet 复核 -> 根因返工”的闭环。

## 生成批次空间策略

- 同一场景先生成 1 张 master establishing pure image，通过后作为同场景视觉参考。
- 同一场景的后续 panel 都必须继承该 master 的墙面材质、光线方向、入口/出口位置和主轴线。
- 不跨场景随机切换色温：游戏厅是 CRT 红蓝绿，小路是旧路灯黄，废楼是冷绿，电话亭是暖白，8-bit 是有限色盘。
- 小路段 `MSB066-MSB119` 必须使用同一条逃跑轴线。
- 废楼段 `MSB120-MSB169` 必须使用同一条走廊纵深轴线。
- 8-bit 段 `MSB170-MSB188` 必须固定 orthographic side-scrolling。

## 跑偏根因表

| 问题 | 根因 | 修正 |
|---|---|---|
| 同场景墙体/入口变化 | prompt 每张重新发明空间 | 回到 scene master + 白模 camera ID |
| 人物左右关系反了 | 未写阵营和轴线 | 加入“三兄弟左/近侧，混混右/远侧，不翻轴” |
| 小路变城市街道 | 环境锚点不够 | 强化围墙、杂草、碎砖石、湿地、旧路灯，禁止车辆 |
| 游戏厅变现代电玩城 | CRT/低天花/烟雾不足 | 加入旧街机、低天花、烟雾、磨损摇杆，禁止液晶屏 |
| 走廊变医院/学校 | 废楼材质不足 | 加入发霉墙、旧消防箱、单位楼、积水，禁止病床/课桌 |
| 电话亭科幻化 | “发光电话亭”被模型理解为科幻 | 强调旧电话亭、旧塑料、玻璃金属框、现实错误物 |
| 8-bit 丢废楼轮廓 | 游戏提示太泛 | 保留像素墙砖、消防箱、电话亭和走廊透视 |

## 复核方法

每个场景生成完一批 pure 后，先做 contact sheet：

- 横向看空间是否连续。
- 竖向看人物是否漂移。
- 用白模联系表对照入口、出口、镜头方向。
- 如果一批里超过 20% 跑偏，停止生成后续图，先修 scene master 或 prompt。
- 如果只有单张跑偏，标记 rejected 并替换，不影响整批。
