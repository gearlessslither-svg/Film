# 投币口 / 01_AIGC 故事阶段连续性规则 v1

## 核心原则

角色不是一张固定人设图从头用到尾。人物的衣服干净程度、表情、身体状态、心理状态、道具状态和环境痕迹，必须随着故事发展逐步变化。

本片开场的三兄弟是干净的小朋友：衣服可以旧、可以不合身、可以有生活磨损，但不能一开始就满身泥灰。打架、摔倒、逃跑、进入废楼以后，衣服和身体状态才逐步变脏、变乱、变紧绷。

如果同一角色在不同剧情阶段出现明显状态变化，必须单独生成人设阶段图或状态参考图。最终分镜 pure 图生成时，必须调用对应阶段的人设，而不是使用单一静态人设。

当前三兄弟 S0 基准人设锁定在 `character_design_v2/THREE_BROTHERS_CHARACTER_REFERENCE_LOCK_v001.md`。任何包含阿磊、小川、小满的分镜/关键帧/视频生成，必须同时调用画面中对应角色的人设图。

## 角色阶段图规则

- 开场基础人设必须是 `S0_START_CLEAN`：旧但干净，不带打架后泥灰。
- 冲突后必须单独出 `S5_ESCAPE_DIRTY` 或 `S6_CORRIDOR_PHONE_SHOCK` 状态图，不能把开场人设直接弄脏靠 prompt 猜。
- 同一家庭角色需要亲缘感，但不能脸部同质化。阿磊必须绑定旧细框眼镜和推眼镜动作；小川是圆眼、右耳外翻、半张嘴、抓书包带；小满是更短的圆头、更圆胖的脸和身体、下垂胆小眼、闭口、干净暖色旧小马甲、抓马甲下摆和脚尖内扣。
- 小川至少需要：开场干净版、石块事故后脏乱版、电话亭光照版、8-bit 像素版。
- 阿磊至少需要：开场干净强撑版、围堵后被推乱版。
- 小满至少需要：开场干净版、墙边冻结/惊吓版。
- 当前已通过的开场三兄弟三视图+表情参考：
  - 阿磊：`character_design_v2/CHR_BRO_A_older_brother_turnaround_expression_v001_glasses.png`
  - 小川：`character_design_v2/CHR_BRO_B_protagonist_turnaround_expression_v001_distinct.png`
  - 小满：`character_design_v2/CHR_BRO_C_younger_brother_turnaround_expression_v001_chubby.png`
- 彬子至少需要：游戏厅自信版、输掉后羞辱版、小路堵截凶狠版、失控后空白版。
- 高杆、大海、小齐至少需要：游戏厅聚拢版、小路堵截版、事故后反应版。

## 分镜生成规则

每张 pure 图 prompt 必须包含：

1. `character_stage_lock`：角色当前阶段。
2. `wardrobe_state`：衣服干净/皱/泥灰/湿/像素化状态。
3. `emotion_state`：当前心理表情，不使用全片通用表情。
4. `environment_stage_lock`：场景当前阶段，不让环境提前或滞后变化。

视频角色负载规则：

- 单条视频生成单元默认只指定一个主要可识别角色，优先小川；其他角色只承担空间、压力、陪伴或阻挡功能。
- 三兄弟同框镜头用于建立身高差、站位和关系时，可以采用背影、侧影、遮挡或远景，避免同时要求三人正脸和复杂表情。
- 需要三人正脸的画面优先作为 pure keyframe 或短静态/微动镜头，不作为长运动镜头的默认方案。
- 混混群体只在彬子需要长期识别；高杆、大海、小齐更多作为体型剪影和包围方向，不要求每条视频都稳定复现脸。

道具因果连续性规则：

- 每个会改变状态的环境物件必须有 `prop_state` 和 `state_cause`。如果当前 panel 没有角色触碰或前一 panel 没有建立动作，物件保持上一状态。
- 门帘/门：未有人到门口前保持自然垂落、关闭或半掩，只允许漏光；只有角色伸手、身体穿过或前一 panel 已明确掀开，才能出现被拉开状态。
- 电话听筒：拿起前在听筒座上；小川伸手或已拿起后才允许悬空、拉线、贴耳。
- 石块：小川发现前在路边地面；伸手抓取后才进入手中；事故后才允许血迹、掉落或旁人反应。
- 街机/屏幕：开机、胜负、故障和 `WIN / INSERT COIN` 必须按剧情阶段出现，不能提前泄露结尾 UI。

白模约束执行规则：

- `whitebox_reference_path` 只是资产索引，不是生成约束。正式生成时必须把白模图实际作为图像参考/图生图输入，或使用 approved mother image + 对应白模共同约束。
- 如果生成器只能接收文字 prompt，结果只能用于探索，不得标记为 `pure_generated_needs_human_review`。
- 同一连续场景必须先锁一个可复用环境母图或高保真场景约束图，再派生后续 panel；不能每张仅靠文字重新描述老小区、门帘、墙面和路径。
- QA 必须检查环境漂移：楼体结构、入口位置、门帘状态、湿地/自行车/晾衣绳锚点、角色行进方向是否仍贴合白模。

禁止：

- 开场三兄弟满身泥灰。
- 把“prompt 里写了白模路径”误当成已经使用白模图像约束。
- 没有角色动作原因的门帘自开、门自开、听筒悬空、石块入手、UI 提前出现。
- 打架前就出现逃跑后的衣服状态。
- 小满长成“小川缩小版”，或者只靠没有红领巾/没有书包来区分。
- 阿磊忘记戴旧细框眼镜，或者把眼镜变成现代潮流大框/墨镜。
- 小满开场穿得邋遢、裤鞋满灰、像后段逃跑状态。
- 事故后小川突然恢复干净。
- 电话亭段忘记小川刚逃跑后的脏乱状态。
- 8-bit 段丢掉现实阶段积累下来的身份锚点。
