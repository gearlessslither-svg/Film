# 投币口 / 01_AIGC 超细分镜规则 v4

## 核心修正

旧版 `03_aigc_storyboard.md` 的 20 镜是叙事分段，不是生产级分镜。它能说明故事顺序，但不能支撑 5-6 分钟 AIGC 视频生产。

新版规则：

- `03_aigc_storyboard.md` 保留为 macro storyboard。
- `12_motion_control_table.md` 保留为 20 镜运动控制。
- `13_generation_units.md` 保留为 27 个视频生成单元。
- 新增 `19_micro_storyboard_188_panels.csv` 作为真正的 storyboard panel 表。
- 每个 panel 是“可生成一张图的明确画面状态”，不是一个完整镜头。

## 数量目标

目标片长按 5 分 40 秒估算，约 340 秒。

| 类型 | 数量 | 用途 |
|---|---:|---|
| 微分镜 panel | 188 | 覆盖完整 5-6 分钟叙事，每张都可生成图 |
| 人物设计图 | 32 | 7 人单人、三视图、表情、姿态、关系和像素转换 |
| 场景/道具设定图 | 24 | 老小区、游戏机房、小路、废楼、电话亭、8-bit、街机、石块等 |
| 白模/构图参考 | 60 | 从现有 21 张扩展到更多中间构图和动作路径 |
| 精修关键帧 | 36 | 每个段落至少 1-3 张用于视频首尾帧 |
| 视频生成首尾帧 | 54 | 对应现有 27 个生成单元的 start/end frame |

总资产规划约 394 张图，不含失败重跑和风格测试。这个数量才接近 5-6 分钟 AIGC 短片的生产密度。

## Panel 密度规则

| 场景类型 | 推荐密度 | 说明 |
|---|---:|---|
| 环境建立 | 4-8 panel / 20 秒 | 空间、光源、入口、方向必须清楚 |
| 角色关系 | 8-12 panel / 30 秒 | 每个眼神、站位、跟随关系都要拆 |
| 对战和羞辱 | 12-18 panel / 40 秒 | 游戏动作、屏幕、脸部反应分开 |
| 堵路和围殴 | 25-35 panel / 60 秒 | 动作高风险，必须拆细 |
| 逃跑 | 12-20 panel / 30 秒 | 起跑、方向、追兵距离和空间转换分开 |
| 电话亭 | 15-22 panel / 45 秒 | 远处发现、靠近、犹豫、接起都要有 |
| 电子化/8-bit | 25-35 panel / 60 秒 | 风格转换、游戏规则、UI 尾针必须拆 |

平均要求：每分钟 30-35 张 panel，安静段略低，动作/转场段更高。

## Panel 字段标准

`19_micro_storyboard_188_panels.csv` 每行必须包含：

| 字段 | 含义 |
|---|---|
| panel_id | `MSB001` 到 `MSB188` |
| clip | 对应 01-20 macro clip |
| beat | 段落动作点 |
| approx_time | 建议时间点 |
| shot_size | 景别 |
| camera | 白模或建议新增机位 |
| image_prompt_focus | 这张图最重要的画面 |
| character_focus | 主要人物 |
| expression_note | 必须锁定的表情 |
| pose_motion_note | 姿态/动作路径 |
| continuity_anchor | 服装、道具、空间、光线锚点 |
| avoid | 本 panel 最容易跑偏的禁止项 |
| asset_type | storyboard / keyframe / start_frame / end_frame / expression / prop |
| priority | A/B/C 生成优先级 |

## 画面生成规则

- 每张 panel 只表达一个画面状态。
- 不允许一行里同时写“走进、打赢、逃跑、电子化”。
- 动作必须拆成：准备、开始、中段、结果、反应。
- 反应必须拆给具体人物，不能只写“大家震惊”。
- 小川的心理变化必须通过身体和眼神表现，不写内心独白。
- 彬子的羞辱感必须先在游戏厅建立，不能到小路突然变坏。
- 石块必须在小路环境里提前出现，再在小川视线里变成焦点。
- 电话亭必须先像现实物件，再变成系统入口。
- 8-bit 段不能突然变成快乐游戏，必须保留废楼和电话亭轮廓。

## 通过标准

- 随机抽 20 张 panel，能看出准确故事顺序。
- 任意相邻 5 张 panel，不需要文字也能连起来。
- 三兄弟每次出现时，身高、衣服、站位关系不漂移。
- 四个混混每次出现时，轮廓和功能不混。
- 小路冲突不是热血动作戏，而是恐惧和失控。
- 8-bit 不是新场景，而是废楼空间被游戏规则重写。
