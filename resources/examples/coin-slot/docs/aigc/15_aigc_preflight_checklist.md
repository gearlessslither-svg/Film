# 投币口 / 01_AIGC 分镜生成前检查表 v1

用途：每次进入图生视频前，先用本表检查对应生成单元。不要直接用长镜头硬跑。

## 单元级检查

| 检查项 | 通过标准 |
|---|---|
| 一镜只做一件事 | 生成单元只有一个核心动作或一个视觉变化 |
| 主体明确 | 谁在动、谁静止、谁只是背景都写清楚 |
| 运动方向明确 | 左/右/前/后/向下/向上/顺时针/逆时针明确 |
| 镜头运动明确 | locked-off、slow dolly in、tracking、handheld、orthographic fixed 等明确 |
| 主体和镜头不冲突 | 主体运动和镜头运动方向不互相打架 |
| 首尾帧明确 | 起点和终点都能被画成静帧 |
| 中间帧判断明确 | 大动作必须拆或补中间帧 |
| 人物位置稳定 | 左/中/右、前景/中景/背景关系不乱 |
| 光线稳定 | 光源方向和色彩不在同镜头内大幅变化 |
| 景别变化不过大 | 不从近景突然跳远景，不从正脸突然跳背影 |
| 多人互动可控 | 围殴、追逐、堵路都拆成短单元 |
| 不遮挡关键身份 | 主角红领巾、绿书包、哥哥/小弟弟关系尽量可见 |
| 不做 180 度翻转 | 走廊、小路、横版关卡都保持轴线 |
| 有隐藏剪辑方案 | 高风险单元有遮挡、闪白、黑场、电话线或 UI 停顿 |
| 有失败修正方案 | 失败后知道先改关键帧、白模、时长还是 prompt |

## 生成前流程

1. 先确认 `16_character_design_bible_v2.md` 和 `17_character_sheet_generation_prompts_v2.md` 的人物设计已经通过。
2. 打开 `19_micro_storyboard_188_panels.csv`，找到对应 MSB panel 和相邻 panel。
3. 打开 `13_generation_units.md`，选择一个生成单元。
4. 打开对应白模图，确认空间轴线。
5. 打开对应关键帧、start frame、end frame 或角色/场景参考。
6. 如本段涉及声音，先查看 `23_dialogue_voice_sound_music_plan.md`，但不要把非画面声音写进图像 prompt。
7. 使用 `14_structured_video_prompts.md` 的对应提示词。
8. 先低清或短秒数测试。
9. 只观察：动作、镜头、空间、身份。
10. 一次只改一个变量。
11. 通过后再提高画质或延长时长。

## 失败处理

| 问题 | 优先处理 |
|---|---|
| 人脸变了 | 缩短时长，减少转头幅度，回到角色表 |
| 人物千人一面 | 回到 `16_character_design_bible_v2.md`，补脸部锚点、姿态和表情，不继续跑视频 |
| 空间乱了 | 回到白模，降低镜头运动，固定前中后景 |
| 动作不连贯 | 增加中间帧，拆短动作，明确方向 |
| 暴力过强 | 减少动作数量，不拍冲击特写，强调停顿和声音抽空 |
| 视频太假 | 减少夸张动作，加真实光线、颗粒、轻微 motion blur |
| 画面漂移 | 使用 locked-off 或小幅 tracking，减少背景复杂度 |
| 8-bit 过现代 | 限制为 1990s side-scrolling beat-em-up, limited color palette |

## 本项目高风险单元

- U10A-U10B：围住哥哥、哥哥失衡。
- U11A-U11C：看见石块、捡起石块、失手后冻结。
- U12A-U12B：主角起跑、追兵反应。
- U18A-U18B：电话线扫描线、身体与走廊电子化。
- U20A-U20C：像素清场、WIN、INSERT COIN。

这些单元必须先短秒测试，不直接高清生成。
