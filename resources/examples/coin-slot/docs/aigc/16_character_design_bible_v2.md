# 投币口 / 01_AIGC 人物设计圣经 v2

## 这次返工要解决的根问题

旧版人物提示词只锁定了“年龄、身份、基本服装和站位”，没有锁定人物的可识别设计。AIGC 会自动把缺失信息补成平均脸、平均体态、平均表情，所以现有人设容易千人一面。

具体缺口：

| 缺口 | 旧版情况 | 新版修正 |
|---|---|---|
| 人物小传 | 只有故事功能，没有生活来源 | 每人都有家庭/性格/恐惧/欲望/关系位置 |
| 外形轮廓 | 身高差有，但脸型、体态、肩颈、手脚缺失 | 每人必须有可远景识别的 silhouette |
| 脸部记忆点 | 缺少五官比例、发际线、眉眼、嘴角、皮肤细节 | 每人 3-5 个脸部锚点 |
| 表情范围 | 基本是中性站姿 | 每人有常态、紧张、撒谎、受辱、失控等表情库 |
| 习惯动作 | “走、看、躲”太泛 | 每人有重复手势、站姿、走路节奏 |
| 服装道具 | 只有类别，没有磨损、来源、穿法 | 每件衣服有颜色、尺寸、旧化、穿法和记忆点 |
| 角色关系 | 三兄弟关系有，但视觉上没有层级 | 通过站位、触碰、视线和保护动作建立关系 |
| 生成约束 | 没有禁止同质化 | 加入“不要统一脸、不要同款发型、不要同款身材”等硬约束 |

## 全局人物设计规则

- 所有角色都必须能在 3 秒远景里被认出，不靠字幕和旁白。
- 三兄弟不能只是三个不同身高的同款男孩：哥哥是“装大人的孩子”，主角是“被推到事件中心的小孩”，小弟弟是“还没理解危险的孩子”。
- 混混四人不能只是四个坏孩子：老大靠羞辱感驱动，瘦高个负责封路，胖子负责身体压迫，小跑腿负责起哄和传染情绪。
- 每个人必须有一个“静止记忆点”和一个“运动记忆点”。静止记忆点用于人设图和关键帧，运动记忆点用于视频生成。
- 不追求漂亮脸。优先真实、偏旧、具体、有小缺陷、有生活痕迹。
- 表情不要都凶或都害怕。每个角色的情绪表达方式必须不同。
- 兄弟可以有亲缘感，但不能共享同一套平均儿童脸。小川和小满必须通过脸型、眼睛、嘴、耳朵、发型、手势和站姿形成可测差异。
- 开场基础人设是旧但干净的孩子。脏、湿、泥、擦伤、衣服歪斜属于后续故事阶段，不能提前带入开场正面设定。

## 三兄弟脸部差异锁

| 维度 | BRO_A 阿磊 | BRO_B 小川 | BRO_C 小满 |
|---|---|---|---|
| 脸型 | 偏方，颧骨低，下巴微抬 | 小窄脸，脸部竖向偏长一点 | 明显更胖更圆，圆额头、鼓脸颊、短脖子，像一颗小圆团 |
| 眼睛 | 戴旧细框近视眼镜，镜片后半眯，眼神从上往下 | 圆眼，紧张时眉心挤起 | 下垂眼/湿润小动物感，反应慢，胆小但不脏乱 |
| 嘴 | 抿住，装镇定 | 半张，像要问又不敢问 | 小嘴闭住或轻轻瘪，不做和小川一样的半张担心 |
| 耳朵 | 普通或贴近头 | 右耳微外翻是小川专属 | 耳朵尽量被碗盖头或脸颊弱化，不能复用右耳外翻 |
| 发型 | 短硬，后脑睡扁 | 家里剪坏短刘海，额前一撮翘发 | 更短的圆寸/短碗盖头，贴头皮，额前短短一排，不要小川同款翘发 |
| 表情机制 | 假装镇定、怕丢脸，紧张时会推眼镜 | 紧张、发问、被恐惧推着动 | 胆小、依赖、慢半拍；害怕时先缩成一团，不是发问 |
| 手势 | 插兜、蹭鼻尖 | 双手攥书包带 | 抓衬衫下摆或抓哥哥衣角 |
| 站姿 | 脚尖外八，撑肩 | 肩缩，身体往书包带里收 | 脚尖内扣，膝盖靠近，身体更圆胖，缩成一小团 |

小满生成失败判定：如果他看起来只是“更矮、更小、更没书包的小川”，必须退回重做。合格的小满应该在遮住衣服颜色后，仍能靠圆额头、下垂眼、闭口茫然、碗盖软发、抓衣角和内扣站姿被认出。

## 三兄弟

### BRO_A / 阿磊 / 哥哥

小传：阿磊是那种在小区里比同龄孩子早熟半步的男孩。他不是真的勇敢，只是习惯在弟弟面前装成什么都懂。父母忙，他经常带两个弟弟下楼玩，所以他把“带路”当成自己的权力。赢下街霸后，他短暂相信自己真的长大了。

外形锚点：

- 脸型偏方，颧骨不高，左眉有一处短断点，戴旧细框近视眼镜，镜片稍旧但干净，眼神总往上挑。
- 头发短而硬，后脑勺压出一点睡扁的形状。
- 身材比主角高一头，肩膀故意撑开，实际仍是儿童骨架。
- 海军蓝旧运动外套，胸前红白斜条，袖口磨毛，拉链头缺漆。
- 裤腿偏长，鞋尖磨白。

表情库：

| 情境 | 表情 |
|---|---|
| 常态 | 嘴角轻轻抿住，下巴微抬，假装镇定 |
| 带弟弟 | 眼神不看弟弟，只用余光确认他们跟上 |
| 赢街霸 | 眉毛扬起，笑只露一点，肩膀抖一下 |
| 被堵 | 眼神先闪一下，再立刻把身体挡到前面 |
| 被围 | 表情从逞强变成怕丢脸，嘴唇咬住 |

动作和姿态：

- 站立时脚尖外八，双手常插外套口袋。
- 紧张或装成熟时会推一下眼镜；赢了以后先推眼镜，再压住笑。
- 带路时步子比弟弟大半拍，经常回头催。
- 被混混围住时仍想把胸口挺起来，但肩膀会先缩。

AI 生成禁区：不要生成成少年英雄、校霸、成熟男主、帅气偶像脸；不要让他比混混更强壮；眼镜不能变成时髦大框、墨镜、护目镜或现代潮牌镜框。

### BRO_B / 小川 / 主角

小传：小川是一年级男孩，还没有形成真正的道德判断，只知道“哥哥被打了，我要让它停下来”。他不是勇敢，而是被恐惧推着做出无法撤回的动作。电话亭和 8-bit 世界是他的心理逃生机制，也是他把现实后果翻译成游戏规则的方式。

外形锚点：

- 脸小，眼睛偏圆，右耳微外翻，鼻梁低，嘴唇常半张。
- 发型是家里剪坏的短刘海，额前有一撮不听话的翘发。
- 蓝白旧校服外套偏大，红领巾系得过紧，领口有点勒。
- 深色短裤，膝盖有旧擦痕，白球鞋发灰。
- 浅绿色书包塌在背上，右侧肩带比左侧更松，前袋拉链缺一个小拉片。

表情库：

| 情境 | 表情 |
|---|---|
| 常态 | 眼睛看别人嘴巴，不敢长时间对视 |
| 进入游戏厅 | 嘴微张，眼睛被 CRT 光照亮 |
| 看到哥哥赢 | 想笑但先看哥哥反应 |
| 小路被堵 | 眉头往中间挤，嘴唇发白 |
| 看见石块 | 眼神突然下坠，脸部僵住 |
| 失手后 | 瞳孔感扩大，嘴巴张开但发不出声 |
| 电话亭前 | 眼泪没落下，呼吸压住，像被声音牵走 |

动作和姿态：

- 紧张时两只手攥书包带，拇指反复揉肩带边缘。
- 走路时总差哥哥半步，想靠近又怕被嫌慢。
- 起跑时不是运动员式冲刺，而是身体先歪、脚步乱、书包猛甩。
- 接电话时手指先碰到听筒又缩一下，再拿起。

AI 生成禁区：不要把小川变成勇敢小英雄、冷酷复仇者、成年化脸、漂亮童模；石块动作必须是慌乱失手，不是攻击姿势。

### BRO_C / 小满 / 小弟弟

小传：小满还太小，对游戏机房和混混都没有完整理解。他只知道哥哥往哪里走，他就跟着。他在冲突时完全僵住，是现实危险感的标尺：如果连最小的孩子都不能动，观众会明白这不是热血冲突。

外形锚点：

- 圆额头很明显，脸更短更圆更胖，脸颊鼓一点，短脖子，整体像一颗小圆团，眼睛略下垂，带一点胆小可爱的湿润感，眼神慢半拍。
- 鼻子小而钝，嘴小，常闭着或轻轻瘪住，不使用小川那种半张嘴的紧张表情。
- 头发更短，是圆寸或很短的碗盖头，贴头皮，额前短短一排，不要小川那撮翘发。
- 换成和小川完全不同的开场衣服：干净暖色旧小马甲或薄棉背心，里面是浅色长袖，衣领和扣子整齐，像被家里人照顾过，不邋遢。
- 裤子偏宽，显得身体圆一点；可以有干净补丁，鞋带系好，鞋旧但不脏，不要泥灰。
- 总贴近哥哥或主角，身体像被旁边人的动作牵着走。

表情库：

| 情境 | 表情 |
|---|---|
| 常态 | 胆小地跟着，眼睛下垂，反应慢半拍，有一点可爱但不卖萌 |
| 进游戏厅 | 被光吓到又好奇，眼睛眨得很快 |
| 哥哥赢 | 先看主角笑不笑，再跟着笑 |
| 被堵 | 下巴收进去，眼睛往上看 |
| 围殴 | 完全僵住，嘴角下压，手不知道放哪里 |

动作和姿态：

- 走路脚尖内扣，步子小。
- 害怕时抓哥哥衣角或抓自己小马甲下摆。
- 冲突中不逃、不喊、不动手，只僵在墙边。

AI 生成禁区：不要让他突然勇敢、参与打斗、变成喜剧调剂或哭闹抢戏；不要长成小川同款圆眼、同款短刺发、同款右耳外翻、同款半张嘴担心脸；不要穿蓝白校服外套、红领巾或书包；不要只靠“更矮”来区分他；不要穿得邋遢、满身灰、裤鞋泥污或像流浪儿童。

## 混混四人组

### BLY_A / 彬子 / 小矮个老大

小传：彬子不是最强壮的人，但他最怕丢脸。他在游戏厅靠狠劲维持地位，输给比自己小的哥哥以后，真正受伤的是秩序感。他找人堵路不是为了钱，而是为了把刚才的羞辱擦掉。

外形锚点：

- 个子矮，脖子短，肩膀紧，脸偏窄但下颌用力。
- 染黄发梢，发根黑，前额几缕头发粘在汗上。
- 破黑夹克偏大，里面黑背心或暗色 T 恤，斜挂旧腰包。
- 左脸靠近嘴角有小痣或旧疤点，嘴角常向一边歪。
- 穿旧拖鞋或开口凉鞋，走路脚跟拖地。

表情库：

| 情境 | 表情 |
|---|---|
| 常态 | 眼睛从下往上瞪人，嘴角歪 |
| 游戏前 | 假笑，故意贴近屏幕和对手 |
| 输掉 | 眨眼次数变少，脸僵住，鼻翼绷紧 |
| 堵路 | 头歪着，下巴往前顶 |
| 准备下狠手 | 眼神短促变空，牙关咬紧 |
| 被失手击中后 | 不拍血腥，只拍不可置信和众人停住 |

动作和姿态：

- 说话时下巴先顶出去，手指戳人胸口附近但不一定碰到。
- 走路先甩肩再迈腿，靠夸张节奏补偿身高。
- 怒时会把腰包往上一拽，像要重新整理自己的面子。

AI 生成禁区：不要变成成年黑帮、帅气反派、冷酷杀手；他是小城坏孩子，不是职业罪犯。

### BLY_B / 高杆 / 瘦高个

小传：高杆不太说话，他靠身高和长手臂制造堵路感。他跟着彬子不是因为忠诚，而是因为站在旁边就能分享权力。他的危险感来自“门闩”一样的身体。

外形锚点：

- 窄长脸，眼皮重，鼻梁长，嘴唇薄。
- 身体高瘦，肩膀塌，手臂显得过长。
- 灰白旧夹克袖子略短，露出手腕骨节。
- 裤子松垮，鞋很脏，鞋带散开但不管。

表情库：

| 情境 | 表情 |
|---|---|
| 常态 | 没什么表情，眼睛半垂 |
| 堵路 | 看人不看脸，像看出口 |
| 围住哥哥 | 轻微皱眉，不兴奋，只觉得麻烦 |
| 失手后 | 第一个往后退半步 |

动作和姿态：

- 常站在路口边缘，手臂横着挡。
- 转身慢，像一根长杆横过画面。
- 推人不用拳头，用肩和前臂。

AI 生成禁区：不要让他变成时髦高个、篮球少年或健壮打手。

### BLY_C / 大海 / 胖子

小传：大海负责让空间变窄。他不一定最坏，但最容易跟着气氛上头。围堵时他的身体就是墙，主角从他旁边看过去，哥哥会显得更小。

外形锚点：

- 圆脸，眼睛小，鼻头亮，脖子短。
- 褪色几何图案 T 恤，领口汗湿，外面可搭旧短袖衬衫。
- 短裤或宽松裤，膝盖和小腿有灰。
- 手掌厚，指甲边有黑泥。

表情库：

| 情境 | 表情 |
|---|---|
| 常态 | 嘴巴微张，呼吸重 |
| 起哄 | 笑得慢，先看彬子脸色 |
| 推搡 | 眉毛往下压，像是在完成任务 |
| 失手后 | 笑意消失，脸突然空掉 |

动作和姿态：

- 走两步抹一下脖子汗。
- 用肩膀和肚子顶人，不做漂亮动作。
- 挡路时双脚站得宽，像把小路堵住。

AI 生成禁区：不要做成喜剧胖子，不要滑稽化；他是压迫感，不是笑点。

### BLY_D / 小齐 / 小跑腿

小传：小齐年龄最小，最怕被四人组排除，所以总是第一个起哄。他的坏不是稳定的恶，而是讨好强者的兴奋。他也最容易在事情失控后慌。

外形锚点：

- 尖下巴，额头窄，眼睛亮但飘。
- 灰外套只扣一颗扣子，里面条纹旧内衫。
- 裤脚一高一低，鞋跟踩扁。
- 手指总在抠袖口或搓衣角。

表情库：

| 情境 | 表情 |
|---|---|
| 常态 | 眼睛飘，嘴角快笑快收 |
| 起哄 | 笑得比别人早，但声音发虚 |
| 堵路 | 故意站得很开，实际随时看彬子 |
| 失手后 | 第一个收声，眼睛快速左右看 |

动作和姿态：

- 一直换重心，脚尖点地。
- 说话时身体前探，话说完马上缩回去。
- 出事后手会先摸自己袖口，不敢看彬子。

AI 生成禁区：不要变成可爱孩子、现代街舞少年或纯路人。

## 关系调度

| 关系 | 视觉规则 |
|---|---|
