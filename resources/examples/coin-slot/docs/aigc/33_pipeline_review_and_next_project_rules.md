# 投币口 / AIGC 影视流程复盘与下一项目基础规则 v1

## 这轮暴露的根问题

1. 人物不是“好看但泛”的问题，而是缺少可测的 face DNA 和阶段状态锁。小满旧图失败的原因不是年龄写得不够小，而是脸型、发型、表情机制和手势都落在小川同一区间。
2. 白模不是参考草图，而是把 AIGC 当渲染器时的空间输入。白模如果重复、遮挡错误、比例不准，后续真实图会继承这些错误。
3. 分镜不是 20 张概念图，而是 5-6 分钟影片的生产栅格。188 张只是最低可执行版本，复杂动作和心理转折仍需要继续加中间帧。
4. 声音不能等画面完成后再补。对白、停顿、环境声、SFX、音乐和剪辑时间必须和分镜表共享同一时间线。
5. pure 图和 annotated 图必须分开。pure 图给模型，不能有制作标注；annotated 图给人和流程，承担判断、返工和沟通。
6. 分镜图不是人设图。角色朝向必须服从镜头动机、行动方向和前后镜头逻辑；不能为了看清脸让角色永远正脸看镜头。
6. AIGC 视频无法像真人拍摄一样稳定承载大量可识别演员。同一镜头的角色负载必须被设计：故事可以有三兄弟和混混群，但视频生成单元应默认只让一个角色承担主要身份和表演压力。
7. 场景固定不等于逻辑固定。所有会改变状态的物件都要有因果锁：谁碰了、什么时候变、上一帧是什么状态。否则 AIGC 会自行把门帘、门、听筒、石块、屏幕 UI 变成“看起来合理但剧情上不成立”的状态。
8. 白模必须作为视觉输入参与生成。把白模文件路径写进 prompt 只是给人看的索引，对模型没有足够约束力；这种 text-only 生成会导致同一场景每张都重新发明空间。

## 下一项目默认流程

### 1. 故事和阶段锁

- 先拆故事阶段：开场、进入、冲突前、冲突中、事故后、逃跑、异化、结尾。
- 每个阶段必须写明角色心理、表情、衣服干净度、道具状态和环境状态。
- 后续分镜、白模、图像 prompt、音频 cue、剪辑表都必须绑定 `story_stage`。

### 2. 人物设计

- 每个角色先写小传、轮廓、五官、服装来源、习惯动作、表情库和禁区。
- 容易混的角色必须写 pairwise contrast：例如主角 vs 弟弟、老大 vs 跑腿。
- 亲属可以有相似感，但必须能在缩略图里靠脸、头发、体态、手势区分。
- 如果剧情导致性格、表情、服装、泥灰、伤痕、道具位置变化，必须追加阶段人设。
- 视频阶段必须区分“故事角色”和“当前镜头识别角色”：小川默认是主要识别主轴；阿磊、小满可以通过身高、背影、侧影、动作和空间位置保持存在感，不必每条视频都清晰露脸。
- 群体角色默认做体型和压迫感设计，除彬子外不逐个承担长期脸部连续性。

### 3. 白模

- 原则上每张 micro storyboard 都应有独立白模图。
- 可以共用白模的情况只有两类：同一机位、同一构图、位移非常小，且故事只需要通过 prompt 改动微表情、手势、UI 或光效。
- 小位移也必须在 prompt 里写明“在这个构图下发生了什么位移”，不能让模型自己猜。
- 白模 QA 必须检查：缺图、空图、低对比、相邻重复、角色遮挡、比例、轴线、主体位置、环境锚点。

### 3.5 镜头-主体逻辑

- 每个含人物 panel 必须先定义 `camera_subject_relation`、`character_facing`、`gaze_target` 和 `camera_motivation`。
- 进入空间、跟拍、逃跑、追逐、靠近目标等镜头，默认应使用背面、三分之二背面、侧面或过肩关系；只有明确 `reaction_cut` 才允许正脸。
- 如果镜头是“跟着角色走”，角色必须看向行动目标，不看镜头。
- 如果镜头是“发现目标”，画面应服务于角色视线与目标关系，不应变成人物正脸摆拍。
- 新增 QA 失败类型：`wrong_camera_subject_relation`、`staged_character_sheet_logic`、`gaze_breaks_story_logic`、`movement_direction_broken`。
- 通用规则沉淀为 `NEW_PROJECT_COPY_PACK_v1/docs/CAMERA_SUBJECT_CONTINUITY_RULES.md`；本项目执行细则见 `34_camera_subject_logic_rules.md`。
- 白模和 prompt QA 还必须检查道具因果：门帘是否有人掀、门是否有人开、听筒是否有人拿、石块是否已经被发现/捡起、屏幕 UI 是否到了该出现的剧情阶段。
- 如果不能实际使用白模图像输入，应先停在 prompt/探索阶段，不进入正式 pure 队列；正式生产必须走“白模图像输入”或“approved mother image + 白模图像输入”。

### 4. 真实图生产

- 先生成角色 S0 clean 基础人设，再生成后段脏乱/受伤/异化阶段人设。
- 每个场景先做 1-3 张真实图试产，验证人设、空间、清洁度、风格，再批量铺开。
- 真实图生成顺序：A 级关键帧 -> start/end frame -> 高风险动作中间帧 -> B/C 级补帧。
- 每张图必须输出 pure 和 annotated 两版。pure 不含制作标注；annotated 后处理叠加必要字段。

### 5. 音频

- 导演需要判断哪些剧情需要对白、旁白、系统声或设计沉默。
- 台词必须写角色口气、潜台词、停顿、麦克风距离和处理方式。
- 音效/音乐单独表格化，不写进图片 prompt，靠 `visual_range` 和时间点关联分镜。
- guide WAV 可以先用本地 TTS 和程序化声音对时，最终再替换为正式表演和声音设计。

### 6. Animatic

- 在真实图未全量完成前，用白模/已完成 pure 图混排成 PPT 式 animatic。
- animatic 必须按 `approx_time` 或剪辑表持续时间输出，并合成 guide WAV。
- 每轮真实图替换后重建 animatic，检查故事节奏、空间连续性和声音点位。

## 对传统影视流程的取舍

保留：

- 人物小传、服装 continuity、场景调度、白模/预演、分镜 animatic、声音 cue sheet、剪辑节奏表。

调整：

- AIGC 不适合靠现场临场调度补救，必须把角色状态、空间、光线和动作路径预先写死。
- 传统分镜可以省略的“中间状态”，在 AIGC 里往往必须拆成图。
- 传统拍摄可以用演员统一角色，AIGC 必须用 face DNA、阶段人设和 QA 维持角色。

放弃：

- 为了“镜头多样性”频繁换轴、换构图、换风格。
- 把声音当后期装饰。
- 用一张漂亮概念图替代可生产的分镜体系。
