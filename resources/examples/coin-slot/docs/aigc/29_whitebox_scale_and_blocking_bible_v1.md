# 投币口 / 01_AIGC 白模比例与 blocking 圣经 v1

## 核心原则

本项目白模按“AI 渲染器输入”标准制作。白模必须尽可能忠实还原最终真实图片的构图、比例、空间关系、人物站位、前中后景和遮挡。它不是草图，也不是漂亮参考图，而是后续 AIGC 生成的空间合同。

如果白模和分镜意图冲突，修白模，不改分镜。

## 单位和人物比例

Blender 白模中 1 unit 近似 1 米。人物采用儿童/少年比例，不按成年人默认身高生成。

| 角色 | 白模高度 | 宽度/体量 | 必须保留的识别锚点 |
|---|---:|---:|---|
| 阿磊 | 1.35 | 瘦但撑肩 | 站在弟弟前方、红领巾、儿童身体但强撑气势 |
| 小川 | 1.08 | 小、圆、收缩 | 浅绿色书包、红领巾、永远低于阿磊 |
| 小满 | 0.95 | 最小、靠后 | 贴近小川或墙边、脚尖内扣、浅色衣块 |
| 彬子 | 1.25 | 矮但横 | 黄发锚点、黑夹克、下巴前顶 |
| 高杆 | 1.75 | 最高最瘦 | 长手臂、灰白夹克边 |
| 大海 | 1.45 | 最宽 | 宽站姿、身体像墙 |
| 小齐 | 1.25 | 窄、飘 | 边缘前探、动作迟疑 |

任何白模如果把小川做得接近成年人、把阿磊做得像成年人、把高杆和其他混混做成同一高度，都视为 `wrong_scale`。

## 环境比例锚点

| 场景 | 硬尺度 | 空间锚点 |
|---|---|---|
| 老旧小区 | 楼体高于人物 3 倍以上，门约 2.0 高 | 游戏机房入口在角落深处，楼道黑洞和门口不能互换 |
| 游戏厅 | 街机约 1.7-1.8 高，低天花约 3.2 高 | 两侧街机夹出窄通道，街霸机是冲突中心 |
| 门口外景 | 卷帘门和招牌压住人物 | 三兄弟从彩光门口离开，冲突不发生在门口 |
| 偏僻小路 | 路宽约 5.0，两侧墙高约 3.6 | 三兄弟在近/左侧，混混在远/右侧，石块在路边前景 |
| 废楼走廊 | 走廊宽约 3.2，高约 3.1 | 入口在近处，电话亭固定在远端 |
| 电话亭 | 约 2.2 高，宽约 1.0 | 旧电话、玻璃/金属框、暖白光；不能变成科幻设备 |
| 8-bit | 横版 orthographic | 主角左，敌人右，电话亭保留为背景锚点 |

## 白模精度分级

| 等级 | 用途 | 是否可进 pure 图 |
|---|---|---|
| L0 场景占位 | 看大概空间 | 不可 |
| L1 macro blocking | 看场景方向和主轴 | 不可 |
| L2 panel blocking | 看主体位置、机位、前中后景 | 可进入人工 QA |
| L3 render reference | 接近最终真实图构图，人物/道具比例可信 | 可作为 pure 图结构参考 |

当前项目目标是 L3。L2 以下白模只能用于排错，不能进入真实图片生成。

## 每格白模规则

- 默认一张 MSB 分镜输出一张白模。
- 同一机位连续镜头仍然输出独立白模，至少要体现人物、道具、光效、UI 或运动状态变化。
- 微小位移如果不影响构图，可以共用构图逻辑，但必须在白模 QA 和 prompt delta 中写清变化。
- 大位移、阵营关系、遮挡、追逃、围堵、石块动作、首尾帧衔接必须独立建模。
- 白模中可以使用简化方块人物，但比例、朝向、站位和遮挡关系必须准确。

## 不允许的修正

- 不允许因为白模不好做而删掉原分镜的机位。
- 不允许把复杂 blocking 改成正反打静态特写。
- 不允许让同一场景入口、出口、电话亭、石块、街霸机在不同 panel 中漂移。
- 不允许用 prompt 文字弥补白模中不存在的空间关系。
