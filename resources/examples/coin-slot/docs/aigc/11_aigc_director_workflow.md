# 投币口 / 01_AIGC AIGC 视频导演工作流 v1

## 核心判断

AIGC 视频不是“拍摄现实”，而是“约束模型推测现实”。本项目的导演工作不是把画面写得更复杂，而是让模型明确：

- 谁在动
- 怎么动
- 朝哪里动
- 摄像机怎么动
- 哪些东西不能变
- 起点是什么
- 终点是什么
- 中间路径是什么

## 项目工作流

1. 剧本转画面：所有情绪必须变成可见行为。
2. 画面转镜头：每个镜头只表达一个核心事件。
3. 镜头转动作：明确主体位置、运动方向、运动幅度和镜头运动。
4. 动作转关键帧：至少有首帧和尾帧，大动作增加中间帧。
5. 关键帧转提示词：提示词必须继承角色、场景、光线、方向和禁止项。
6. 低成本测试：先短秒数、低成本，只看运动、空间、身份是否稳定。
7. 修正运动：运动路径错时优先改关键帧，不只改 prompt。
8. 修正一致性：人物漂移回人设，空间漂移回白模。
9. 高清生成：运动和身份稳定后再提高画质。
10. 剪辑统一：用调色、颗粒、插帧、声音和隐藏剪辑统一质感。

## 动作风险分级

| 类型 | 可用动作 | 使用方式 |
|---|---|---|
| 稳定动作 | 转头、停下、抬手、靠近、慢推、低位跟拍、轻微环绕 | 可用于 3-5 秒生成单元 |
| 伪运动 | 烟雾、CRT 闪烁、灯管闪、衣服晃、书包晃、积水反光 | 用来增加电影感，不改变主体关系 |
| 中风险动作 | 三人同行、四人堵路、主角起跑、电话线晃动、像素敌人入场 | 保持方向单一，避免镜头同时大幅运动 |
| 高风险动作 | 围殴、石块失手、追逐、电子化、8-bit 清场 | 必须拆成 1.5-3 秒生成单元 |

## 镜头运动原则

- 主体向右时，镜头优先向右跟随。
- 主体向前时，镜头可以 slow dolly in。
- 主体后退或冻结时，镜头保持 locked-off 或轻微 push-in。
- 多人互动时，镜头不要旋转，不做 180 度翻转。
- 走廊段保持同一纵深轴线，电话亭固定在深处。
- 8-bit 段固定为 orthographic side-scrolling，不做 3D 旋转。

## 关键帧原则

- 每个生成单元必须有首帧和尾帧描述。
- 角色身份、服装、发型、书包、红领巾、混混轮廓不能漂移。
- 关键帧之间的差异不要过大：不要正脸近景直接跳到背影远景。
- 围殴、失手、追逐、电子化、清场必须使用动作路径拆解。
- KF07 只作为安全环境/道具关键帧，实际失手动作由生成单元控制。

## 提示词结构

每个生成单元按以下顺序写：

1. Camera：镜头高度、方向、运动和景别。
2. Subject：主体是谁，位于画面哪里，正在做什么。
3. Motion：运动方向、速度、幅度和节奏。
4. Scene：环境、前景、中景、背景。
5. Lighting：光源方向、色彩和稳定性。
6. Style：写实、梦核、像素、CRT 等风格。
7. Keep consistent：人物脸、服装、道具、空间结构、色调、光源方向。
8. Avoid：变脸、肢体扭曲、额外角色、空间重构、突然跳切、现代物件。

## 隐藏剪辑策略

| 场景 | 可用隐藏剪辑 |
|---|---|
| 游戏机房 | CRT 闪白、屏幕光扫脸、机器侧边遮挡 |
| 游戏机房门口到小路 | 门帘擦镜、暗处过门、钠灯曝光变化 |
| 偏僻小路冲突 | 人影遮挡、手持晃动、声音抽空、路灯拖影 |
| 逃跑到废楼 | 黑墙擦过镜头、快速横移、呼吸声盖剪辑点 |
| 电话亭 | 铃声节奏、听筒 close-up、电话线 match cut |
| 电子化到 8-bit | CRT 扫描线、像素块、强光闪白 |
| 8-bit 结尾 | UI 停顿、`WIN` 静止、`INSERT COIN` 闪烁 |

## 返工优先级

1. 动作不对：缩短生成单元，增加中间帧。
2. 空间乱：回到 Blender 白模，降低镜头运动幅度。
3. 人物漂移：回到角色表，减少转头和遮脸。
4. 暴力过强：减少动作细节，强调慌乱、停顿和声音抽空。
5. 画面太假：减少夸张动作，增加真实光线、颗粒、轻微运动模糊。
6. 画质不足：最后再高清化，不提前牺牲运动稳定性。
