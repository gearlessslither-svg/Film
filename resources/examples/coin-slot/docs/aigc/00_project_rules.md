# 投币口 / 01_AIGC 项目规则

## 基本规格

- 项目类型：中式梦核 / 90年代小城 / 街机异化短片
- 生产优先级：AIGC 视频优先，正常拍摄版后置翻译
- 推荐时长：3-5 分钟
- 推荐画幅：16:9 横屏电影短片版，后续可转 9:16 竖屏版
- 视觉策略：先用 Blender 白模锁空间和机位，再用 AIGC 生成风格化关键帧和视频段落

## AIGC 生成原则

- 每个视频段落只允许一个主要变化：移动、转身、追逐、电子化、像素化、战斗清场等不要混在同一条里。
- AIGC 视频镜头必须控制角色负载：同一视频段落原则上只让 1 个角色承担清晰身份和表演压力；三人同框优先承担空间关系、身高差、行进方向和气氛，不同时要求三张脸、三套表情和复杂同步动作都稳定。
- 三兄弟是故事核心，但视频生成应默认以小川为识别主轴。阿磊和小满在多数运动镜头里可用背影、侧影、半遮挡、远景、局部动作或低频正脸出现；只有关系建立和关键反应镜头才要求三人清晰同框。
- 混混和路人除彬子外默认是群体压力，不作为长期可识别角色逐个锁脸；可用轮廓、背影、遮挡、统一色块和空间包围感表达。
- 所有人物、服装、道具、位置关系、光源方向必须持续锁定。
- 人物连续性不是“一张人设图从头用到尾”。每个角色必须按故事阶段锁定表情、服装干净程度、身体状态和道具状态；最终分镜生成时必须调用对应阶段的人设或状态参考。
- 开场三兄弟是旧衣服但干净的小朋友：可以旧、磨损、不合身，但不能满身泥灰。围堵、推搡、石块事故、逃跑和废楼段之后，才允许逐步变皱、变脏、沾湿泥、书包歪斜。
- 如果同一角色在不同剧情阶段出现明显变化，必须补出阶段版人设图；不能只在 prompt 里临时写“更脏一点”来替代资产。
- 亲属角色也必须有明确差异。三兄弟可以有家庭相似感，但不能共享同一张平均儿童脸；小川和小满尤其要在脸型、眼神、发型、表情机制、手势和站姿上分开。
- 从 2026-05-28 起，任何包含三兄弟的正式分镜、关键帧、视频提示词或图像编辑，必须调用 `character_design_v2/THREE_BROTHERS_CHARACTER_REFERENCE_LOCK_v001.md` 中列出的对应人设参考图；不能只靠文字描述生成三兄弟。
- 环境也有阶段状态：同一空间在入口、对峙、事故、逃跑、电话亭、8-bit 化时应分别锁定光线、湿度、破损痕迹和可见锚点，不能提前或滞后。
- 场景不要靠单条提示词临场发明，要继承白模中的空间关系和固定机位。
- 只在文字 prompt 里写白模路径，不算真正使用白模约束。正式 pure 图必须把对应白模图作为图像参考/图生图输入，或先使用 approved mother image 再叠加对应白模约束；否则只能算 text-only exploration，不能进入正式 pure 队列。
- 道具和环境状态必须有因果：门帘、门、电话听筒、石块、书包、灯、街机屏幕等，只能在画面中有角色动作或前一 panel 已建立原因后改变状态。没人触碰门帘时，门帘不能自己被掀开；没人拿起听筒时，听筒不能离座；石块被捡起前必须仍在地面。
- 叙事层可以保留 20 个左右 macro clip，用来控制故事顺序和段落节奏；生产层必须拆成大量 micro storyboard panel。
- 5-6 分钟短片的微分镜目标不少于 180 张 panel；动作、冲突、电子化和 8-bit 段必须拆得更细。
- 每个 macro clip 必须包含 start frame、end frame、允许变化、禁止变化和转场衔接。
- 每个 micro storyboard panel 只表达一个画面状态：准备、开始、中段、结果、反应必须拆开。
- 分镜、白模、pure 图、annotated 图、音频 cue 和剪辑表必须共享同一套 `story_stage`。阶段定义以 `31_story_stage_continuity_rules.md` 和导出表 `exports/panel_stage_state_map.csv` 为准。
- 分镜图必须遵守镜头-主体逻辑：角色朝向、视线和身体运动方向服从镜头动机，不默认正脸看镜头。进入空间、跟拍、逃跑、追逐、靠近目标等镜头应优先使用背面、三分之二背面、侧面或过肩关系；只有明确反应镜头才允许正脸。执行细则见 `34_camera_subject_logic_rules.md`。

## 主体连续性锁定

- 三兄弟：没有女生。哥哥带着主角和更小的弟弟去偏僻游戏机房。
- 哥哥：10-11岁，工作名阿磊，稍高，像孩子里的“大人”，戴旧细框近视眼镜，旧海军蓝运动外套，左眉短断点，下巴微扬，带头行动，负责和混混老大街霸对战并打赢。
- 主角：小学一年级男孩，7岁左右，工作名小川，瘦小，右耳微外翻，蓝白旧校服外套，小红领巾系得过紧，深色短裤，白色旧球鞋，浅绿色塌书包；他在偏僻小路上看见老大准备下狠手时，恐惧中捡起路边石块失手砸中老大头部。
- 小弟弟：5-6岁，工作名小满，比主角更小更圆胖，短圆头，干净暖色旧小马甲或薄棉背心，胆小、软圆、略可爱但不卖萌，抓马甲下摆，脚尖内扣，跟在两人后面，冲突时僵住不敢动手。
- 当前 S0 三兄弟基准参考：
  - 阿磊：`character_design_v2/CHR_BRO_A_older_brother_turnaround_expression_v001_glasses.png`
  - 小川：`character_design_v2/CHR_BRO_B_protagonist_turnaround_expression_v001_distinct.png`
  - 小满：`character_design_v2/CHR_BRO_C_younger_brother_turnaround_expression_v001_chubby.png`
- 混混四人组：高杆/瘦高个、彬子/小矮个老大、大海/胖子、小齐/小跑腿。
- 小矮个老大：彬子，最凶狠，个子矮但气势强，破黑夹克，黄发或染色发梢，腰包，拖鞋，廉价金属链；他输掉街霸后因为羞辱感找茬。
- 关键道具：街霸街机、街机硬币、旧书包、路边石块、电话听筒、电话线、CRT 屏幕扫描线、像素 UI。
- 结尾文字：先出现巨大像素 `WIN`，短暂停顿后角落闪出 `INSERT COIN`。

## 空间连续性锁定

- 老旧小区：非常老旧、偏僻、潮湿的一楼角落，游戏机房藏在居民楼底商/储物间一样的房子里。
- 游戏厅：低天花板，左右两侧街机，入口在前方，老板柜台在一侧，核心街机是街头霸王，CRT 彩光和烟雾。
- 偏僻小路：三兄弟赢了游戏后回家经过的小路，老小区背后或侧面，围墙、杂草、旧路灯、潮湿地面、碎砖石；混混四人组在这里堵住他们。
- 游戏机房门口/离开点：脏台阶，卷帘门，旧招牌，昏黄路灯，杂乱电线；只负责承接“从游戏机房出来回家”，真正冲突发生在偏僻小路。
- 废楼走廊：狭窄、低天花板、重复门洞、冷绿灯管，尽头出现电话亭。
- 电话亭：不合理地位于废楼内部，发出稳定微光，是电子化入口。
- 8-bit 世界：废楼空间被横版清版街机规则重写，但仍保留电话亭、墙砖、消防箱和走廊轮廓。

## Blender 白模用途

- 白模负责锁定空间结构、相机轴线、角色行进方向和关键物件位置。
- 白模渲染图不是最终画面，只作为 AIGC 图生图或视频生成的结构参考。
- 每个分镜镜头都应绑定一个 Blender camera ID，例如 `CAM_ARCADE_01` 或 `CAM_PHONE_02`。
