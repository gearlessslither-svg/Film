# 投币口 / 01_AIGC 负面约束 v1

## 全局禁止

- 不要现代智能手机、现代游戏机、电竞网吧、液晶显示器、LED 大屏。
- 不要赛博朋克城市、未来机甲、霓虹摩天楼、科幻实验室。
- 不要把主角变成成年人、超级英雄、战士、武侠人物或机器人。
- 不要改变主角服装锚点：蓝白旧校服外套、小红领巾、深色短裤、白色旧球鞋、浅绿色旧书包。
- 不要把三兄弟变成男女混合小队；这组三人全是男孩。
- 不要把混混四人组混成无差别路人；小矮个老大、瘦高个、胖子、小跑腿必须轮廓不同。
- 不要过度血腥，不要英雄化暴力，不要让打人变成爽片现实动作。
- 不要出现大量无关群众、警察、现代车辆、学校操场、医院走廊。
- 不要把中式梦核变成欧美恐怖片或日式校园怪谈。
- 不要让每个镜头风格突变；同一段落内保持色彩、空间、材质一致。

## 人物同质化禁止

- 不要统一脸型、统一发型、统一身材、统一皮肤质感。
- 不要把三兄弟做成同款校服儿童模特；阿磊、小川、小满必须通过脸、体态、表情和动作区分。
- 不要让阿磊只是“更高的小川”；他必须有旧细框近视眼镜、装成熟的下巴、旧海军蓝外套、左眉断点和撑肩姿态。
- 不要让小川只是“普通小学生”；他必须有过紧红领巾、浅绿色塌书包、攥书包带、右耳微外翻和惊恐迟滞。
- 不要让小满只是“更小的孩子”；他必须有短圆头、更圆胖的脸和身体、干净暖色旧小马甲、胆小可爱的下垂眼、抓马甲下摆、脚尖内扣和反应慢半拍。不要给他蓝白校服、红领巾、书包，不要把他做得邋遢、脏、像流浪儿童。
- 不要把混混四人组做成同一类脏衣服少年；彬子短小前压、高杆高瘦封路、大海宽身体堵路、小齐飘动起哄。
- 不要所有人都摆同一种凶狠表情；每个人的常态、害怕、愤怒、受辱和迟疑必须不同。
- 不要漂亮化、网红化、童模化、动漫化，也不要把混混拍成成年人黑帮。

## 游戏厅段禁止

- 不要现代电玩城、VR 设备、抓娃娃机主题乐园。
- 不要高大通透空间；必须是低矮、拥挤、烟雾、CRT 光。
- 不要把孩子拍成青春期少年；必须是小学一年级的体量。
- 不要过早出现像素化或科幻特效；最多允许 CRT 闪烁和轻微录像带噪点。

## 偏僻小路/追逐段禁止

- 不要城市主干道、大车流、现代商业街。
- 不要把真正暴力放在游戏厅内；暴力发生在回家路上的偏僻小路。
- 不要复杂格斗编排；石块失手只能是慌乱、短促、意外。
- 不要把石块变成刀、棍、凳子或刻意武器。
- 不要让追逐方向反复变化；保持从偏僻小路逃向废楼方向。

## 废楼走廊段禁止

- 不要鬼、怪物、血手印、宗教符号。
- 不要突然换成学校、医院、酒店、地下停车场。
- 不要大幅空间扭曲；只允许走廊重复、拉长、灯管闪烁。
- 不要让电话亭位置漂移；电话亭固定在走廊深处。

## 电话亭/电子化段禁止

- 不要现代公用电话亭、智能屏幕、透明全息设备。
- 不要直接出现 Matrix 风格绿色代码雨；这里优先 CRT 扫描线、像素块、低分辨率色彩错位。
- 不要让男孩离开电话亭位置再电子化；位置必须固定，变化发生在身体和空间材质上。

## 8-bit 街机段禁止

- 不要 3D 卡通游戏、现代手游 UI、高清 anime 战斗。
- 不要西方街头背景；背景必须保留废楼走廊的像素化轮廓。
- 不要复杂连招或镜头旋转；横版固定机位，动作清晰。
- 不要可爱化结尾；`WIN` 后必须保留 `INSERT COIN` 的不安尾针。
