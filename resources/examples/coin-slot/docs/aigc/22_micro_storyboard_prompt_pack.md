# 投币口 / 01_AIGC 微分镜图像提示词使用说明 v1

完整提示词表：`exports/micro_storyboard_image_prompts.csv`，共 188 行，对应 MSB001-MSB188。

## 使用方式

1. 不要直接一次生成 188 张。先按 `20_micro_storyboard_generation_batches.md` 选择批次。
2. 每批先生成 A 级 priority，再补 B/C。
3. 每条使用 `zh_prompt` 作为正向提示词，`negative_prompt` 作为负向提示词。
4. 生成后按 `continuity_check` 检查，不通过就先返工人物或白模，不进入视频。
5. 所有角色必须先通过 `character_design_v2_asset_plan.csv` 中的人物设定图。

## 示例

- 计划路径：`micro_storyboard_panels/B01/MSB001_01_空镜压低视线.png`
- 正向提示词：90年代中国小城，中式梦核现实电影质感，潮湿发黄的童年记忆，低照度，轻微 VHS 噪点，儿童低视角，真实旧衣服和生活痕迹，不漂亮化。人物必须继承 v2 设定：阿磊海军蓝旧运动外套和左眉断点；小川右耳微外翻、过紧红领巾、浅绿色塌书包；小满浅色大衬衫、抓衣角、脚尖内扣；彬子黄发梢、破黑夹克、腰包；高杆高瘦长手臂；大海宽身体褪色 T 恤；小齐条纹内衫和抠袖口。 画面编号 MSB001，段落 01《老小区建立》。景别：远景。参考机位：CAM_COMPOUND_01_ESTABLISH。本张只画一个画面状态：空镜压低视线。画面焦点：潮湿地面和破自行车占前景，居民楼底层角落被压在画面右后方。人物焦点：环境。表情要求：无人物，只有潮湿和静默。姿态/运动路径：locked-off，低机位，轻微前推。连续性锚点：老旧居民楼一楼偏僻角落、发黄水泥墙、晾衣绳、破自行车、潮湿地面、门内微弱 CRT 蓝绿光。画面应像可用于电影分镜的单张 production storyboard panel，构图清楚，动作状态明确，不要把前后动作合在一张里。

- 检查：确认 环境 可识别；确认 老旧居民楼一楼偏僻角落、发黄水泥墙、晾衣绳、破自行车、潮湿地面、门内微弱 CRT 蓝绿光 未漂移；确认只表达「空镜压低视线」一个状态。
