# 投币口 / 02_Normal_Shooting 故事大纲 v2

## Logline

90年代小城里，一个稍大的哥哥带着主角和更小的弟弟去老小区角落里的游戏机房。哥哥在街霸机上打赢小矮个混混老大后，三兄弟在回家偏僻小路上被四人堵住；主角慌乱中用路边石块失手打伤老大，逃入废楼，接起一通不该存在的电话，现实被重写成街机游戏。他在游戏规则里清空追兵，却在 `WIN` 之后看见 `INSERT COIN`。

## 故事结构

| Beat | 内容 | 情绪 | 拍摄策略 |
|---|---|---|---|
| Establish | 老旧小区一楼偏僻角落，哥哥带主角和小弟弟去游戏机房 | 偷感、兴奋、关系建立 | 儿童低机位，三人前中后调度，老小区环境压住画面 |
| Arcade | 三兄弟进入低矮游戏机房，被街机光吸引 | 兴奋、危险边缘 | CRT 光、烟雾、硬币声、街霸机作为核心道具 |
| Seed | 哥哥和小矮个老大对战街霸并赢下，小矮个丢脸 | 小胜利、羞辱、埋雷 | over-shoulder 看屏幕，老大反应压暗 |
| Exit | 哥哥志得意满带弟弟回家，三人从门口进入更暗的小路 | 开心转不安 | 从彩色 CRT 光切到昏黄路灯，方向保持一致 |
| Ambush | 四个混混在偏僻小路堵住三兄弟，围住哥哥 | 压迫、危险 | 长焦压缩，小矮个在前，瘦高个和胖子封路 |
| Incident | 老大准备下狠手，主角捡起路边石块失手打中对方 | 惊吓、失控 | 声音抽空，动作短促，不做血腥特写 |
| Chase | 主角丢下原地混乱的人，沿小路狂奔，后方追声逼近 | 恐惧、求生 | handheld tracking，方向从小路深处通往废楼 |
| Maze | 主角钻入废楼，走廊像无限延伸 | 孤立、迷失 | 冷绿灯管、重复门洞、慢速推镜 |
| Threshold | 电话亭发光，男孩接起电话 | 被召唤、临界 | locked-off，暖白光对冷绿环境 |
| Transformation | 世界电子化，空间展平成街机舞台 | 失重、规则替换 | 扫描线、像素块、match cut、合成 |
| Payoff | 男孩像游戏角色清空追兵，出现 `WIN` 和 `INSERT COIN` | 爽感、不安 | 8-bit 动画/合成/投影或全动画段落 |
