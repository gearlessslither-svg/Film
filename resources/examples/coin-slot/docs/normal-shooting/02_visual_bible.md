# 投币口 / 02_Normal_Shooting 视觉圣经 v2

## 场景

- 老旧小区：发黄水泥墙、潮湿地面、铁栏杆、晾衣绳、破自行车，游戏机房藏在一楼偏僻角落，像储物间改造。
- 游戏机房：低矮、拥挤、烟雾、CRT 彩光、旧海报、磨损摇杆、老板柜台，核心机器是街头霸王。
- 游戏机房门口/离开点：脏台阶、旧卷帘门、褪色招牌、杂乱电线，门内漏出街机红蓝光；只做离开承接。
- 偏僻小路：老小区背面或侧面的狭窄小路，围墙、杂草、潮湿地面、碎砖石、旧路灯，是堵截和失手的主场景。
- 废楼走廊：狭窄、低天花板、重复门洞、发霉墙面、冷绿色灯管、地面积水。
- 电话亭：旧式电话亭，不合理地出现在废楼内部，发出稳定暖白光。
- 街机世界：可用 8-bit 动画、像素合成、LED/投影辅助或后期全动画完成，背景保留废楼轮廓。

## 摄影

- 老小区建立：儿童低机位，24mm，让三兄弟从院子深处走向一楼角落。
- 游戏机房：24-35mm，轻微 handheld，靠 CRT 光塑造脸部，屏幕与人物反应交叉剪辑。
- 街霸对战：over-shoulder 和 insert 结合，强调哥哥赢、老大丢脸，不提前现实动手。
- 偏僻小路堵截：长焦压缩或低机位广角，四人封住路口，哥哥被推到中心，主角在边缘。
- 石块失手：短焦中近景，动作短促后停顿，避免任何英雄化摆拍。
- 逃跑：tracking handheld，保持从偏僻小路逃向废楼方向。
- 废楼：locked-off 与 slow dolly-in 为主，减少花哨运动，强调空间不合理。
- 电话亭：明暗对比强，暖白电话亭光对冷绿走廊。
- 8-bit 段：从电影透视转成横版正交构图。

## 灯光

- 老小区：阴天散射光或傍晚低照度，墙面潮湿发黄。
- 游戏机房：CRT 屏幕光为主，顶部旧荧光灯为辅，烟雾吃光。
- 偏僻小路：钠灯黄 + 远处居民窗光，石块失手瞬间可让红色街机记忆或路灯拖影压入画面。
- 废楼：冷绿灯管，走廊深处黑，电话亭暖白光形成唯一安全感。
- 电子化：扫描线、屏幕闪烁、色块错位从电话线开始蔓延。

## 美术与服装

- 哥哥：10-11岁，稍高，短发，旧运动外套或旧校服外套，走在前面，像孩子里的“大人”。
- 主角：7岁左右，蓝白旧校服外套，小红领巾，深色短裤，白色旧球鞋，浅绿色旧书包。
- 小弟弟：5-6岁，短发，旧浅色上衣，冲突时僵住不敢动。
- 小矮个老大：最凶狠，破黑夹克，黄发或染色发梢，腰包，拖鞋，廉价金属链。
- 瘦高个、胖子、小跑腿：身形轮廓必须明显不同，不要变成一群普通路人。
- 道具：旧街机、硬币、摇杆、路边石块、电话听筒、电话线、旧海报、消防箱。

## VFX

- 现实段只做轻微 VHS 噪点、CRT 闪烁和灯光闪烁。
- 电话段做扫描线、像素块、轮廓分解、空间展平。
- 8-bit 段建议后期全动画或合成，保留废楼轮廓作为关卡背景。
