# 投币口 / 02_Normal_Shooting 导演提案 v2

## 核心判断

- 类型：中式梦核 / 90年代小城 / 童年惊悚 / 街机异化
- 时长：3-5 分钟
- 画幅：16:9，后续可剪 9:16
- 核心情绪：一次孩子之间的逞强胜利，滑向无法承担的现实后果，再被街机规则荒诞重写
- 观看体验：先建立三兄弟的关系和老小区空间，再让“赢街霸”变成冲突种子，最后进入逃跑、废楼、电话亭和 8-bit 清版世界

## 导演阐述

本片的现实部分要从具体的90年代小城生活质感开始：老旧小区的偏僻一楼角落、像储物间改出的游戏机房、低天花板、CRT 光、烟味、硬币声，以及孩子之间“哥哥带弟弟见世面”的微妙秩序。

真正的冲突不放在游戏机房门口，而放在回家路上的偏僻小路。哥哥刚赢了小矮个老大的街霸，带着两个弟弟志得意满地离开；这份小小的胜利在小路上被反噬。四个混混堵住三兄弟，围住哥哥，小弟弟僵住，主角在老大准备下狠手时捡起路边石块失手打中对方。这个“意外”是后面狂奔和躲入废楼的心理发动机。

电话亭是现实和系统之间的入口。它不能一开始就像科幻设备，而应该像一个错误出现在废楼里的日常物件。男孩接起电话后，空间被电子化，废楼走廊展平成横版街机舞台。结尾的 `WIN` 是爽点，也是反讽：男孩赢了游戏，但也可能被游戏吞掉。

## 参考适用说明

| 参考方向 | 适合用在哪里 | 抽象技法 | 不建议照搬 |
|---|---|---|---|
| 90年代中国小城纪实质感 | 老小区、游戏机房、偏僻小路 | 低照度、脏旧材质、儿童低视角、生活物件压迫感 | 不要拍成怀旧 MV |
| 旧街机/街头霸王 | 冲突种子 | 对战屏幕、围观、输赢羞辱、CRT 颜色压脸 | 不要把现实冲突拍成擂台爽片 |
| 清版街机/热血格斗 | 最后一幕8-bit战斗 | 横版构图、受击闪白、血条、WIN UI | 不要让现实暴力英雄化 |
| 电话作为现实切换接口 | 电话亭电子化 | 日常物件触发世界切换 | 不要直接复制绿色代码雨 |
| 中式梦核空间 | 废楼走廊 | 重复门洞、冷绿灯管、空间拉长 | 不要加鬼怪或民俗符号 |
