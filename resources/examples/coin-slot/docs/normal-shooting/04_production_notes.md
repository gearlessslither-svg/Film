# 投币口 / 02_Normal_Shooting 制作备注 v2

## 可拍摄性

- 老旧小区和游戏机房门口最好选同一处或可连续调度的场地，确保“角落里的游戏机房 -> 回家小路 -> 废楼方向”空间关系可信。
- 游戏机房可以用小型棚景或真实旧房间改造，核心是低天花板、旧街机/替代柜体、CRT 光感和烟雾。
- 偏僻小路需要有围墙、杂草、碎砖石和旧路灯，石块必须是环境里自然存在的道具。
- 废楼走廊最好用真实长走廊或搭建局部重复墙面，后期通过剪辑和轻微 VFX 做“无限延伸”。
- 电话亭可以作为唯一重点实物道具，必须有可控暖白内光。
- 8-bit 段不建议实拍硬做，建议用像素动画/合成，或者用 Blender 白模作为场景几何参考后再风格化。

## 低成本替代

- 街机不足时，用木箱白模 + CRT 屏幕光 + 近景 insert 补足质感。
- 街霸画面可用授权素材、原创替代画面或后期生成的仿90年代格斗游戏 UI，不依赖真实游戏版权画面。
- 小路不够深时，通过长焦压缩、烟雾、前景墙面和剪辑隐藏实际长度。
- 废楼空间不足时，重复拍同一段走廊，通过镜像、调色和剪辑制造空间循环。
- 电话亭可用旧电话柜/玻璃框架改造，不必完全真实公共电话亭。
- 电子化可用图层位移、扫描线、像素化、色彩错位和 match cut 完成。

## 声音重点

- 老小区：远处居民声、脚步、风吹晾衣绳、隐约街机声。
- 游戏机房：硬币、摇杆、按钮、CRT 电流声、街机音乐。
- 街霸胜利：胜利音效后短暂失真，给小矮个老大的羞辱留一拍。
- 偏僻小路冲突：环境声压低，推搡声和呼吸放大，石块失手后声音抽空。
- 逃跑/废楼：脚步回声、灯管电流、远处电话铃。
- 8-bit：街机战斗音乐、受击音、胜利音效，最后回到电话铃或待机声。

## 和 AIGC 版保持一致

- 不改变三兄弟关系：哥哥、主角、小弟弟，全是男孩。
- 不改变混混四人组：小矮个老大、瘦高个、胖子、小跑腿。
- 不把暴力提前放进游戏机房；真实冲突发生在回家路上的偏僻小路。
- 不把石块换成凳子、棍子、刀或刻意武器。
- 不改变主角服装、电话亭位置、结尾 `WIN / INSERT COIN`。
- 正常拍摄版可以增加镜头数量，但情绪顺序和空间方向必须与 `01_AIGC` 一致。
