## Next Project Checklist

- Create or verify a complete storyboard script before final image generation.
- Generate or select character references and environment master plates before final frames.
- Use whitebox only as spatial guidance; keep whitebox proxies out of final story folders.
- Require final video frames to be single full-frame images, not collages or reference sheets.
- Run exact hash QA and perceptual/visual QA before promotion.
- Keep whitebox, references, final story frames, and rejected assets in separate contact sheets.
- Use a separate style-variant bible and output folder for major art-direction changes.
- Render to a fresh output path and run a decode check.
